## 2차시 - NumPy와 다차원 배열

- NumPy는 다차원 배열 자료구조를 다루는 데 유용하다.
- 2차원 데이터가 여러 층으로 쌓이면 3차원 배열로 생각할 수 있다.
- NumPy array와 Python list의 차이를 학습했다.
  - 메모리 구조
  - 데이터 타입
  - 연산 방식

### NumPy 배열

- `ndim` : 배열의 차원 수
- `shape` : 배열의 각 차원 크기
- 1차원 배열 : `(열)`
- 2차원 배열 : `(행, 열)`
- 3차원 배열 : `(차원, 행, 열)`

### Axis

다차원 배열에서 다음 axis의 의미와 정렬 방향을 학습했다.

- `axis=0`
- `axis=1`
- `axis=2`

`np.sort()`를 사용할 때 axis에 따라 정렬 결과가 어떻게 달라지는지 이해하는 것이 중요하다.

- 단위 벡터(Unit Vector)는 크기가 1인 벡터이다.
- 기존 벡터와 방향은 같으면서 크기만 1로 표현한다.
